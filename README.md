# CarWith · 国际版澎湃（HyperOS Global）实测分享

在 **国际版 Redmi K90** + **国际版澎湃** 上加装 CarWith，并在车端实测通过。

## 实测结论

| 项目 | 结果 |
|------|------|
| 手机 | **国际版 Redmi K90** |
| 系统 | **国际版澎湃（HyperOS Global）** |
| 车型 | **MIHO**、**小鹏 G6** |
| 状态 | **均可成功连接 / 投屏使用** |

> 其他机型与车机版本未逐一验证。加装通常需要 Root / LSPosed 等能力，请先备份并阅读安装说明。
